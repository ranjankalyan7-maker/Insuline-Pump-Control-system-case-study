# Insulin Pump Control System – Case Study

## 📘 Project Overview
This repository contains a Software Engineering case study on the **Insulin Pump Control System**, prepared as part of the BCA 3rd Semester academic curriculum.

The report explains the software engineering concepts involved in designing and analysing a conceptual insulin pump control system, including requirements analysis, system architecture, workflow, UML modelling, data flow, safety, security, and software testing.

## 🎯 Objectives
- Understand the working of an Insulin Pump Control System.
- Study functional and non-functional requirements.
- Understand high-level system architecture.
- Represent system workflow using flowcharts and UML models.
- Study Software Development Life Cycle (SDLC).
- Understand safety, security, and risk management.
- Learn software testing and test case preparation.

## 📚 Topics Covered
- Introduction
- Problem Statement and Objectives
- Scope and Stakeholders
- Existing and Proposed System
- System Components
- Requirements Analysis
- System Architecture
- System Workflow
- Flowchart and Use Case Model
- Data Flow Diagram and Activity Model
- Software Development Life Cycle
- Safety, Security and Risk Management
- Software Testing and Test Cases
- Advantages and Limitations
- Future Scope
- Conclusion, Glossary and References
